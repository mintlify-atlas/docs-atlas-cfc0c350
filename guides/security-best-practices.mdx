## Security Notice

<Warning>
**Critical Information:**

This library is **not designed to be fully side-channel resistant**. We build higher-level protocols on top of a side-channel resistant foundation of elliptic curve operations (generated by fiat-cryptography) and big integer operations (wrapping saferith and BoringSSL), but the protocol-level code is not hardened against all side-channel attacks.

**This library is intended for use by experienced cryptographers and developers** who understand the security implications of the protocols involved. If you are not familiar with the underlying cryptographic primitives, consult with a cryptography expert before using this library in production.
</Warning>

## Audit Status

<Note>
The threshold signing packages of this library and all their direct and indirect dependencies have been **audited by [Trail of Bits](https://github.com/trailofbits/publications#cryptography-reviews)**.

The audit report is available in the repository's `audits/` directory.
</Note>

## In Scope vs Out of Scope

### In Scope (Production-Ready)

These components are audited and considered production-ready:

- **Threshold Signature Schemes**
  - Threshold Schnorr (Lindell22)
  - Threshold ECDSA (DKLs23, Lindell17)
  - Threshold BLS (Boldyreva02)
- **Direct and indirect dependencies** of threshold signatures
- **Cryptographic primitives** used by threshold protocols
- **Key generation protocols** (Gennaro DKG)
- **Memory safety** in critical paths

### Out of Scope (Experimental)

<Warning>
Everything that is **not a direct or indirect dependency of threshold signature schemes** is considered **experimental** and is **not part of the bug bounty program**.

These include:
- Standalone commitment schemes not used in threshold signatures
- Oblivious transfer protocols not used in signing
- Experimental hash functions
- Example code and utilities
</Warning>

## Production Deployment Guidelines

### 1. Version Management

<Warning>
**Always use the latest released version** of bron-crypto. Security updates are only applied to the most recent release.
</Warning>

```bash
# Update to latest
go get -u github.com/bronlabs/bron-crypto

# Pin to specific audited version in production

```

### 2. Random Number Generation

<Warning>
**Critical: Always use cryptographically secure PRNGs**
</Warning>

```go
import "github.com/bronlabs/bron-crypto/pkg/base/prng/pcg"

// GOOD: Use system randomness
prng := pcg.NewRandomised()

// BAD: Never use weak seeds
// prng := pcg.New(12345, 67890) // Predictable!

// GOOD: Seed from crypto/rand for reproducible testing
seed := make([]byte, 16)
if _, err := rand.Read(seed); err != nil {
    panic(err)
}
prng := pcg.NewFromBytes(seed)
```

<Accordion title="Available PRNG Options">

Bron Crypto provides multiple CSPRNG implementations:

```go
import (
    "github.com/bronlabs/bron-crypto/pkg/base/prng/csprng/nist"
    "github.com/bronlabs/bron-crypto/pkg/base/prng/csprng/rfc8937"
    "github.com/bronlabs/bron-crypto/pkg/base/prng/csprng/fkechacha20"
)

// NIST-approved DRBG
prng := nist.NewCTRDRBG()

// RFC 8937 ChaCha20-based
prng := rfc8937.New()

// FKE ChaCha20 (fastest)
prng := fkechacha20.New()
```

For production, prefer NIST DRBG or RFC 8937 for compliance.

</Accordion>

### 3. Key Management

#### Never Store Complete Private Keys

```go
// GOOD: Each party stores only their share
type KeyStorage struct {
    Share       *Shard          // This party's secret share
    PublicKey   *PublicKey      // Joint public key
    Threshold   uint            // Required signers
    Shareholders []sharing.ID   // All parties
}

// Store shares securely
func StoreShare(share *Shard) error {
    // Encrypt before storage
    encrypted := encryptShare(share, storageKey)
    return secureStorage.Write(encrypted)
}

// BAD: Never reconstruct the full private key
// combinedKey := reconstructPrivateKey(shares) // NEVER DO THIS!
```

#### Secure Share Storage

<Steps>

<Step title="Encrypt Shares at Rest">

```go
import "crypto/aes"

func encryptShare(share *Shard, key []byte) ([]byte, error) {
    // Serialize share
    plaintext, err := serde.MarshalCBOR(share)
    if err != nil {
        return nil, err
    }
    
    // Encrypt with AES-GCM
    block, err := aes.NewCipher(key)
    if err != nil {
        return nil, err
    }
    
    gcm, err := cipher.NewGCM(block)
    if err != nil {
        return nil, err
    }
    
    nonce := make([]byte, gcm.NonceSize())
    if _, err := rand.Read(nonce); err != nil {
        return nil, err
    }
    
    ciphertext := gcm.Seal(nonce, nonce, plaintext, nil)
    return ciphertext, nil
}
```

</Step>

<Step title="Use Hardware Security Modules (HSM)">

For high-security deployments:

```go
// Store shares in HSM
type HSMKeyStore struct {
    hsmClient *HSMClient
}

func (k *HSMKeyStore) StoreShare(id sharing.ID, share *Shard) error {
    // HSM encrypts and stores the share internally
    return k.hsmClient.SecureStore(
        fmt.Sprintf("share-%d", id),
        share,
    )
}

func (k *HSMKeyStore) GetShare(id sharing.ID) (*Shard, error) {
    // HSM decrypts and returns share
    return k.hsmClient.SecureRetrieve(
        fmt.Sprintf("share-%d", id),
    )
}
```

</Step>

<Step title="Implement Access Controls">

```go
type SecureShareStore struct {
    store    map[sharing.ID]*Shard
    mu       sync.RWMutex
    allowed  map[sharing.ID]bool
}

func (s *SecureShareStore) GetShare(
    requester sharing.ID,
    target sharing.ID,
) (*Shard, error) {
    s.mu.RLock()
    defer s.mu.RUnlock()
    
    // Only allow parties to access their own shares
    if requester != target {
        return nil, errs.New("unauthorized access")
    }
    
    if !s.allowed[requester] {
        return nil, errs.New("party not authorized")
    }
    
    share, ok := s.store[target]
    if !ok {
        return nil, errs.New("share not found")
    }
    
    return share, nil
}
```

</Step>

</Steps>

### 4. Session Isolation

<Warning>
**Always use unique session contexts** to prevent replay attacks and nonce reuse.
</Warning>

```go
import (
    "github.com/bronlabs/bron-crypto/pkg/mpc/session"
    "github.com/bronlabs/bron-crypto/pkg/network"
)

// GOOD: Create unique session for each protocol execution
func NewSigningSession(
    message []byte,
    quorum network.Quorum,
    timestamp time.Time,
) *session.Context {
    // Include message, quorum, and timestamp in session ID
    sid := network.NewSID(
        message,
        quorumBytes(quorum),
        timestampBytes(timestamp),
    )
    
    return session.NewContext(sid, quorum)
}

// BAD: Never reuse contexts
// globalCtx := session.NewContext(...) // NEVER DO THIS!
// for _, msg := range messages {
//     sign(msg, globalCtx) // Reuses nonces!
// }
```

### 5. Network Security

#### Transport Layer Security

```go
import "crypto/tls"

// GOOD: Use TLS 1.3 for transport
func NewSecureDelivery(
    cert tls.Certificate,
    caCerts *x509.CertPool,
) (*TLSDelivery, error) {
    config := &tls.Config{
        Certificates: []tls.Certificate{cert},
        ClientCAs:    caCerts,
        ClientAuth:   tls.RequireAndVerifyClientCert,
        MinVersion:   tls.VersionTLS13,
        CipherSuites: []uint16{
            tls.TLS_AES_256_GCM_SHA384,
            tls.TLS_CHACHA20_POLY1305_SHA256,
        },
    }
    
    return &TLSDelivery{
        config: config,
    }, nil
}
```

#### Message Authentication

```go
import "crypto/hmac"
import "crypto/sha256"

type AuthenticatedDelivery struct {
    inner   network.Delivery
    authKey []byte
}

func (d *AuthenticatedDelivery) Send(to sharing.ID, message []byte) error {
    // Compute HMAC
    mac := hmac.New(sha256.New, d.authKey)
    mac.Write(message)
    tag := mac.Sum(nil)
    
    // Prepend tag to message
    authenticated := append(tag, message...)
    return d.inner.Send(to, authenticated)
}

func (d *AuthenticatedDelivery) Receive() (sharing.ID, []byte, error) {
    from, authenticated, err := d.inner.Receive()
    if err != nil {
        return 0, nil, err
    }
    
    // Verify HMAC
    if len(authenticated) < 32 {
        return 0, nil, errs.New("message too short")
    }
    
    tag := authenticated[:32]
    message := authenticated[32:]
    
    mac := hmac.New(sha256.New, d.authKey)
    mac.Write(message)
    expected := mac.Sum(nil)
    
    if !hmac.Equal(tag, expected) {
        return 0, nil, errs.New("authentication failed")
    }
    
    return from, message, nil
}
```

### 6. Input Validation

```go
// Always validate protocol inputs
func ValidateThresholdParams(thresh, total uint) error {
    if thresh == 0 {
        return errs.New("threshold must be positive")
    }
    if total == 0 {
        return errs.New("total must be positive")
    }
    if thresh > total {
        return errs.New("threshold exceeds total parties")
    }
    if total > MaxParties {
        return errs.New("too many parties")
    }
    return nil
}

// Validate message sizes
func ValidateMessage(msg []byte) error {
    if len(msg) == 0 {
        return errs.New("empty message")
    }
    if len(msg) > MaxMessageSize {
        return errs.New("message too large")
    }
    return nil
}

// Validate party authorization
func ValidateQuorum(quorum network.Quorum, ac AccessStructure) error {
    if !ac.IsAuthorized(quorum) {
        return errs.New("quorum not authorized")
    }
    return nil
}
```

### 7. Error Handling

<Warning>
**Be careful with error messages** - don't leak sensitive information.
</Warning>

```go
// GOOD: Generic error for external consumption
func SafeError(err error) error {
    if err == nil {
        return nil
    }
    // Log detailed error internally
    log.Printf("Internal error: %+v", err)
    // Return generic error to user
    return errs.New("protocol execution failed")
}

// BAD: Leaking internal state
// return fmt.Errorf("invalid signature from party %v with share %x", id, share)
```

#### Identifiable Abort

```go
import "github.com/bronlabs/bron-crypto/pkg/base"

// Check for malicious party identification
if err != nil {
    culprits := errs.HasTagAll(err, base.IdentifiableAbortPartyIDTag)
    if len(culprits) > 0 {
        log.Printf("Malicious parties detected: %v", culprits)
        // Take action: ban parties, alert admins, etc.
        for _, id := range culprits {
            blacklist.Add(id.(sharing.ID))
        }
    }
    return err
}
```

## Side-Channel Considerations

### Constant-Time Operations

The library uses constant-time primitives where critical:

```go
import "github.com/bronlabs/bron-crypto/pkg/base/nt/numct"

// Constant-time modular arithmetic
result := numct.ModExp(base, exponent, modulus)

// These operations use BoringSSL's constant-time implementations
```

<Note>
**What's Protected:**
- Elliptic curve operations (via fiat-cryptography)
- Big integer arithmetic (via saferith and BoringSSL)  
- Modular exponentiation
- Field arithmetic

**What's NOT Protected:**
- Protocol-level logic
- Message routing
- Network timing
- Memory access patterns in higher-level code
</Note>

### Timing Attack Mitigations

```go
// GOOD: Use constant-time comparison
import "crypto/subtle"

if subtle.ConstantTimeCompare(mac1, mac2) != 1 {
    return errs.New("MAC mismatch")
}

// BAD: Timing-dependent comparison
// if bytes.Equal(mac1, mac2) { // Leaks timing info!
```
