## Overview

The `sharing` package defines interfaces and implementations for secret sharing schemes. Secret sharing allows a dealer to distribute a secret among n shareholders such that only authorized subsets can reconstruct it.

**Location**: `pkg/mpc/sharing/`

## Core Concepts

Secret sharing enables:
- **Threshold reconstruction**: Any t of n shares can recover the secret
- **Information-theoretic security**: Fewer than t shares reveal no information
- **Verifiability**: Shareholders can verify their shares without interaction
- **Linear operations**: Shares support homomorphic operations

## Interface Hierarchy

### SSS (Secret Sharing Scheme)

```go
type SSS[S Share[S], W Secret[W], DO DealerOutput[S], AC accessstructures.Monotone] interface {
    Name() Name
    Deal(secret W, prng io.Reader) (DO, error)
    DealRandom(prng io.Reader) (DO, W, error)
    Reconstruct(shares ...S) (secret W, err error)
    AccessStructure() AC
}
```

Base interface for all secret sharing schemes providing dealing and reconstruction.

### VSSS (Verifiable Secret Sharing Scheme)

```go
type VSSS[S Share[S], W Secret[W], V VerificationMaterial, DO VerifiableDealerOutput[S, V], AC accessstructures.Monotone] interface {
    SSS[S, W, DO, AC]
    Verify(share S, reference V) error
    ReconstructAndVerify(reference V, shares ...S) (secret W, err error)
}
```

Extends SSS with ability to verify shares against public verification material.

### LSSS (Linear Secret Sharing Scheme)

```go
type LSSS[S LinearShare[S, SV], SV any, W Secret[W], WV algebra.GroupElement[WV], DO DealerOutput[S], AC accessstructures.Linear, DF any] interface {
    SSS[S, W, DO, AC]
    DealAndRevealDealerFunc(secret W, prng io.Reader) (DO, DF, error)
    DealRandomAndRevealDealerFunc(prng io.Reader) (DO, W, DF, error)
    ConvertShareToAdditive(S, *unanimity.Unanimity) (*internal.AdditiveShare[WV], error)
}
```

Scheme where shares form a vector space, supporting Lagrange interpolation and additive conversion.

### Lagrange Coefficients

```go

    field algebra.PrimeField[FE],
    sharingIDs ...sharing.ID,
```

Computes the Lagrange basis polynomial values at x=0 for the given set of shareholder IDs.

For shareholder i in set S, the coefficient λ\_i is computed as the product over all other shareholders j in S of j/(j-i).

</ParamField>

<ResponseField name="ds.Map[sharing.ID, FE]">
  Map from shareholder ID to Lagrange coefficient
</ResponseField>

### Shamir Usage Example

```go
import (
    "github.com/bronlabs/bron-crypto/pkg/base/curves/k256"
    "github.com/bronlabs/bron-crypto/pkg/mpc/sharing"
    "github.com/bronlabs/bron-crypto/pkg/mpc/sharing/accessstructures/threshold"
    "github.com/bronlabs/bron-crypto/pkg/mpc/sharing/scheme/shamir"
)

// 1. Setup
field := k256.NewScalarField()
threshold := uint(3)
total := uint(5)
shareholders := sharing.NewOrdinalShareholderSet(total)
accessStructure, err := threshold.NewThresholdAccessStructure(threshold, shareholders)
scheme, err := shamir.NewScheme(field, accessStructure)

// 2. Create and share secret
secret := shamir.NewSecret(field.FromUint64(42))
output, err := scheme.Deal(secret, prng)
shares := output.Shares()

// 3. Reconstruct from threshold shares
subsetShares := []shamir.Share[FE]{shares.Get(1), shares.Get(2), shares.Get(3)}
reconstructed, err := scheme.Reconstruct(subsetShares...)

// Verify: reconstructed.Equal(secret) == true
```

## Pedersen VSS

**Location**: `pkg/mpc/sharing/vss/pedersen/`

Pedersen VSS extends Feldman with information-theoretic hiding using dual generators.

### Scheme

```go
func NewScheme[GE algebra.PrimeGroupElement[GE, S], S algebra.PrimeFieldElement[S]](
    key *pedersen.Key[GE, S],
    ac *threshold.Threshold,
) (*Scheme[GE, S], error)
```

Creates a Pedersen VSS scheme.

<ParamField path="key" type="*pedersen.Key[GE, S]" required>
  Pedersen commitment key with two generators (g, h)
</ParamField>

<ParamField path="ac" type="*threshold.Threshold" required>
  Threshold access structure
</ParamField>

### Commitment

Pedersen commitments use dual generators:
- **Commitment**: C_i = g^{a_i} · h^{r_i}
- **Hiding**: Perfectly hides polynomial coefficients
- **Binding**: Computationally binding under discrete log assumption

## Security Properties

### Information-Theoretic Security

- **t-1 shares reveal nothing**: Any set of fewer than t shares provides no information about the secret
- **Perfect secrecy**: Security holds even against computationally unbounded adversaries
- **Unconditional security**: No cryptographic assumptions required

### Verifiability

- **Feldman VSS**: Public verification using discrete log commitments
- **Pedersen VSS**: Information-theoretic hiding with computational binding
- **Share validation**: Shareholders can verify correctness of their shares

### Homomorphic Properties

- **Addition**: Shares can be added component-wise
- **Scalar multiplication**: Shares can be multiplied by constants
- **Linear combinations**: Support arbitrary linear operations

## Performance Considerations

- **Shamir dealing**: O(nt) field operations for n parties, threshold t
- **Reconstruction**: O(t²) field operations for Lagrange interpolation
- **Verification**: O(t) group exponentiations for Feldman/Pedersen
- **Memory**: O(n) shares to store, O(t) for verification vector

## Error Handling

- **ErrIsNil**: Nil argument provided
- **ErrFailed**: Operation failed (e.g., insufficient shares)
- **ErrMembership**: Invalid shareholder ID or set
- **ErrVerification**: Share verification failed
