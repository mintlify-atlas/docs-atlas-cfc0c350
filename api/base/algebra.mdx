## Overview

The `algebra` package provides a comprehensive hierarchy of algebraic structures used throughout the cryptographic library. These structures define the mathematical properties and operations for cryptographic primitives.

## Core Concepts

### Element and Structure

```go pkg/base/algebra/basic.go
type (
    // Element represents a member of an algebraic structure
    Element[E any] = crtp.Element[E]
    
    // Structure represents an algebraic structure
    Structure[E any] = crtp.Structure[E]
    
    // FiniteStructure is a structure with finite order
    FiniteStructure[E any] = crtp.FiniteStructure[E]
)
```

### Type Utilities

```go pkg/base/algebra/basic.go
// Check if structure implements a specific type
func StructureIs[S crtp.Structure[E], E any](s Structure[E]) bool

// Cast structure to specific type
func StructureAs[S crtp.Structure[E], E any](s Structure[E]) (S, error)

// Cast structure or panic
func StructureMustBeAs[S crtp.Structure[E], E any](s Structure[E]) S
```

## Usage Examples

### Working with Groups

```go
import (
    "github.com/bronlabs/bron-crypto/pkg/base/algebra"
    "github.com/bronlabs/bron-crypto/pkg/base/curves/k256"
)

func groupExample() {
    curve := k256.NewCurve()
    
    // Get the group structure
    group := curve
    
    // Group operations
    g := group.Generator()
    identity := group.OpIdentity()
    
    // Point addition (group operation)
    p1 := g.Add(g)  // 2*G
    p2 := g.Add(g).Add(g)  // 3*G
    
    // Group inverse
    negG := g.Neg()
    
    // Check identity
    sum := g.Add(negG)
    isIdentity := sum.Equal(identity)  // true
}
```

### Working with Fields

```go
import (
    "github.com/bronlabs/bron-crypto/pkg/base/algebra"
    "github.com/bronlabs/bron-crypto/pkg/base/curves/k256"
    "github.com/bronlabs/bron-crypto/pkg/base/prng/pcg"
)

func fieldExample() {
    curve := k256.NewCurve()
    field := curve.ScalarField()
    prng := pcg.NewRandomised()
    
    // Sample random field element
    a, _ := field.Random(prng)
    b, _ := field.Random(prng)
    
    // Field operations
    sum := a.Add(b)           // Addition
    product := a.Mul(b)       // Multiplication
    inverse := a.Inv()        // Multiplicative inverse
    negation := a.Neg()       // Additive inverse
    
    // Field identity elements
    zero := field.Zero()
    one := field.One()
    
    // Verify field properties
    _ = a.Mul(inverse).Equal(one)  // a * a^(-1) = 1
    _ = a.Add(negation).Equal(zero) // a + (-a) = 0
}
```

### Type Casting

```go
import (
    "github.com/bronlabs/bron-crypto/pkg/base/algebra"
    "github.com/bronlabs/bron-crypto/pkg/base/curves/k256"
)

func typeCastingExample() error {
    curve := k256.NewCurve()
    
    // Get scalar structure
    scalarStruct := curve.ScalarStructure()
    
    // Cast to specific type
    field, err := algebra.StructureAs[algebra.PrimeField[*k256.Scalar]](scalarStruct)
    if err != nil {
        return err
    }
    
    // Or use must version (panics on failure)
    field2 := algebra.StructureMustBeAs[algebra.PrimeField[*k256.Scalar]](scalarStruct)
    
    // Check type
    isPrimeField := algebra.StructureIs[algebra.PrimeField[*k256.Scalar]](scalarStruct)
    _ = isPrimeField  // true
    
    return nil
}
```

## Algebraic Hierarchy

The structures follow a mathematical hierarchy:

```
Magma
 ├─ SemiGroup (+ associativity)
    ├─ Monoid (+ identity)
       ├─ Group (+ inverses)
          ├─ AbelianGroup (+ commutativity)
             └─ PrimeGroup (+ prime order)

DoubleMagma
 ├─ HemiRing
    ├─ SemiRing
       ├─ Rig (+ multiplicative identity)
          ├─ Rng (+ additive inverses)
             ├─ Ring (+ multiplicative identity)
                ├─ EuclideanDomain (+ division)
                   └─ Field (+ multiplicative inverses)
                      └─ FiniteField (+ finite order)
```

## Common Patterns

### Generic Operations

All structures support generic operations through their interfaces:

```go
// Group operations
func groupOp[G algebra.GroupElement[G]](a, b G) G {
    return a.Add(b)
}

// Ring operations
func ringOp[R algebra.RingElement[R]](a, b R) R {
    sum := a.Add(b)
    product := a.Mul(b)
    return sum.Add(product)
}

// Field operations
func fieldOp[F algebra.FieldElement[F]](a, b F) F {
    return a.Mul(b.Inv())
}
```

### Structure Constraints

Use algebraic structures as type constraints:

```go
// Function that works with any abelian group
func sumElements[G algebra.AbelianGroupElement[G, S], S algebra.RingElement[S]](elements []G) G {
    result := elements[0].Structure().OpIdentity()
    for _, elem := range elements {
        result = result.Add(elem)
    }
    return result
}
```
