## Overview

The `curves` package provides implementations of various elliptic curves used in zero-knowledge proofs and cryptographic protocols. All curves implement a common interface with support for point operations, scalar multiplication, and hash-to-curve.

## Core Interfaces

### Curve Interface

```go pkg/base/curves/curves.go
type Curve[P Point[P, F, S], F algebra.FiniteFieldElement[F], S algebra.PrimeFieldElement[S]] interface {
    EllipticCurve[P, F, S]
    algebra.PrimeOrderEllipticCurve[P, F, S]
    HashWithDst(dst string, message []byte) (P, error)
    algebra.FiniteStructure[P]
    ScalarField() algebra.PrimeField[S]
}
```

## Supported Curves

The library provides implementations for the following curves:

### Curve25519

```go pkg/base/curves/curve25519/curve.go
const (
    CurveName = "curve25519"
    Hash2CurveSuite = "curve25519_XMD:SHA-512_ELL2_NU_"
)

func NewCurve() *Curve
func NewPrimeSubGroup() *PrimeSubGroup
```

Curve25519 is a Montgomery curve known for its efficient implementation and side-channel resistance.

**Properties:**
- 128-bit security level
- Cofactor: 8
- Efficient scalar multiplication
- Used in Ed25519 and X25519

### Edwards25519

```go
func NewPrimeSubGroup() *PrimeSubGroup
```

The twisted Edwards form of Curve25519, used in the Ed25519 signature scheme.

### secp256k1 (k256)

```go
func NewCurve() *Curve
```

The Koblitz curve used in Bitcoin and Ethereum.

**Properties:**
- 128-bit security level
- Efficient endomorphism for fast scalar multiplication
- ECDSA signatures

### P-256 (secp256r1)

```go
func NewCurve() *Curve
```

NIST P-256 curve, widely used in TLS and government applications.

### Pasta Curves

```go
func NewPallasCurve() *Curve
func NewVestaCurve() *Curve
```

Cycle of curves where each curve's base field is the other's scalar field. Designed for recursive SNARKs.

### BLS12-381

```go
func NewG1() *G1
func NewG2() *G2
```

Parable-friendly curve used in BLS signatures and advanced zero-knowledge proofs.

**Properties:**
- 128-bit security level
- Type III pairing
- Embedding degree 12

```go pkg/base/curves/curve25519/curve.go
// Multi-scalar multiplication
func (*Curve) MultiScalarMul(scalars []*Scalar, points []*Point) (*Point, error)
```

**Example:**

```go
import (
    "github.com/bronlabs/bron-crypto/pkg/base/curves/k256"
    "github.com/bronlabs/bron-crypto/pkg/base/prng/pcg"
)

func scalarMultiplicationExample() {
    curve := k256.NewCurve()
    prng := pcg.NewRandomised()
    
    // Generate random scalar
    scalar, _ := curve.ScalarField().Random(prng)
    
    // Scalar multiplication with generator
    point := curve.ScalarBaseMul(scalar)
    
    // Multi-scalar multiplication
    scalars := []*k256.Scalar{scalar1, scalar2, scalar3}
    points := []*k256.Point{point1, point2, point3}
    result, _ := curve.MultiScalarMul(scalars, points)
}
```

## Hash-to-Curve

All curves support deterministic mapping from arbitrary byte strings to curve points.

```go pkg/base/curves/curve25519/curve.go
// Hash to curve with default DST
func (c *Curve) Hash(bytes []byte) (*Point, error)

// Hash to curve with custom DST
func (*Curve) HashWithDst(dst string, bytes []byte) (*Point, error)
```

**Example:**

```go
import "github.com/bronlabs/bron-crypto/pkg/base/curves/k256"

func hashToCurveExample() {
    curve := k256.NewCurve()
    
    message := []byte("hash this message to a point")
    point, _ := curve.Hash(message)
    
    // With custom domain separation tag
    dst := "myapp.example.com"
    point2, _ := curve.HashWithDst(dst, message)
}
```

The implementation follows RFC 9380 (Hash to Elliptic Curve) standards.

## Complete Example

```go
import (
    "fmt"
    "github.com/bronlabs/bron-crypto/pkg/base/curves/k256"
    "github.com/bronlabs/bron-crypto/pkg/base/prng/pcg"
)

func completeExample() error {
    // Initialize curve
    curve := k256.NewCurve()
    prng := pcg.NewRandomised()
    
    // Generate random scalar
    secret, err := curve.ScalarField().Random(prng)
    if err != nil {
        return err
    }
    
    // Compute public key
    publicKey := curve.ScalarBaseMul(secret)
    
    // Serialize
    encoded := publicKey.ToCompressed()
    fmt.Printf("Compressed point: %x\n", encoded)
    
    // Deserialize
    decoded, err := curve.FromCompressed(encoded)
    if err != nil {
        return err
    }
    
    // Verify equality
    if !decoded.Equal(publicKey) {
        return fmt.Errorf("points don't match")
    }
    
    // Hash to curve
    message := []byte("example message")
    hashedPoint, err := curve.Hash(message)
    if err != nil {
        return err
    }
    
    // Multi-scalar multiplication
    scalars := []*k256.Scalar{secret, secret}
    points := []*k256.Point{publicKey, hashedPoint}
    result, err := curve.MultiScalarMul(scalars, points)
    if err != nil {
        return err
    }
    
    fmt.Printf("Result: %s\n", result.String())
    return nil
}
```

## Performance Considerations

### Optimizations

- **Constant-time operations**: All implementations use constant-time arithmetic to resist timing attacks
- **Endomorphism acceleration**: Curves like k256 use GLV endomorphism for faster scalar multiplication
- **Precomputation**: Fixed-base scalar multiplication (e.g., with generator) uses precomputed tables
- **Parallel processing**: Multi-scalar multiplication parallelizes operations

### Benchmarking

Typical operation timings on modern hardware:

| Operation | Curve25519 | secp256k1 | BLS12-381 G1 |
|-----------|------------|-----------|---------------|
| Scalar Mul | ~50μs | ~80μs | ~200μs |
| Addition | ~0.5μs | ~0.5μs | ~1μs |
| Multi-scalar (n=10) | ~300μs | ~500μs | ~1.5ms |
