## Overview

The encryption package provides generic interfaces for public-key encryption schemes and concrete implementations including:

- **Paillier**: Additively homomorphic encryption for secure computation
- **HPKE (RFC 9180)**: Hybrid Public Key Encryption for modern authenticated encryption

## Core Interfaces

### Scheme

The main encryption scheme interface that provides factory methods for key generation, encryption, and decryption.

```go
type Scheme[SK, PK, M, C, N, KG, ENC, DEC] interface {
    Name() Name
    Keygen(...KeyGeneratorOption) (KG, error)
    Encrypter(...EncrypterOption) (ENC, error)
    Decrypter(SK, ...DecrypterOption) (DEC, error)
}
```

### KeyGenerator

Generates public/private key pairs for encryption schemes.

```go
type KeyGenerator[SK, PK] interface {
    Generate(prng io.Reader) (SK, PK, error)
}
```

### Encrypter

Encrypts plaintexts to ciphertexts using a recipient's public key.

```go
type Encrypter[PK, M, C, X] interface {
    Encrypt(plaintext M, receiver PK, prng io.Reader) (ciphertext C, nonceOrCapsule X, err error)
}
```

### Decrypter

Decrypts ciphertexts back to plaintexts using the private key.

```go
type Decrypter[M, C] interface {
    Decrypt(ciphertext C) (plaintext M, err error)
}
```

## Paillier Encryption

Paillier is an additively homomorphic public-key encryption scheme that allows computation on encrypted data without decryption.

### Features

- **Additive Homomorphism**: `Enc(m1) * Enc(m2) = Enc(m1 + m2)`
- **Scalar Multiplication**: `Enc(m)^k = Enc(k * m)`
- **Rerandomization**: Ciphertexts can be rerandomized to hide which plaintext they encrypt
- **CRT Optimization**: Private key operations use Chinese Remainder Theorem for speed

### Creating a Scheme

```go
scheme := paillier.NewScheme()
```

### Self-Encryption (CRT Optimized)

For encrypting to yourself, use the optimized self-encrypter:

```go
selfEnc, err := scheme.SelfEncrypter(sk)
ciphertext, nonce, err := selfEnc.SelfEncrypt(plaintext, prng)
```

### Homomorphic Operations

#### Addition

```go
// Enc(m1 + m2) = Enc(m1) * Enc(m2)
cSum := c1.Op(c2)
```

#### Scalar Multiplication

```go
// Enc(k * m) = Enc(m)^k
cScaled := c.Act(k)
```

#### Rerandomization

```go
cRerand, newNonce, err := c.ReRandomise(pk, prng)
```

### Complete Example

```go
package main

import (
    "github.com/bronlabs/bron-crypto/pkg/base/prng/pcg"
    "github.com/bronlabs/bron-crypto/pkg/encryption/paillier"
)

func main() {
    prng := pcg.NewRandomised()
    
    // Setup
    scheme := paillier.NewScheme()
    kg, _ := scheme.Keygen()
    sk, pk, _ := kg.Generate(prng)
    
    // Encrypt two values
    enc, _ := scheme.Encrypter()
    pts := pk.PlaintextSpace()
    m1, _ := pts.Sample(nil, nil, prng)
    m2, _ := pts.Sample(nil, nil, prng)
    
    c1, _, _ := enc.Encrypt(m1, pk, prng)
    c2, _, _ := enc.Encrypt(m2, pk, prng)
    
    // Homomorphic addition: c3 = Enc(m1 + m2)
    c3 := c1.Op(c2)
    
    // Decrypt
    dec, _ := scheme.Decrypter(sk)
    result, _ := dec.Decrypt(c3)
    
    // result == m1 + m2
}
```

## HPKE (Hybrid Public Key Encryption)

HPKE (RFC 9180) combines a KEM (Key Encapsulation Mechanism) with authenticated encryption to provide secure, efficient hybrid encryption.

### Features

- **RFC 9180 Standard**: IETF standard for hybrid encryption
- **Multiple Modes**: Base, PSK, Auth, AuthPSK for different authentication models
- **Curve Support**: P-256 and X25519
- **AEAD Algorithms**: AES-128-GCM, AES-256-GCM, ChaCha20Poly1305

### Location

Source: `~/workspace/source/pkg/encryption/hpke/hpke.go:1`

### Constants

#### Modes

- `Base` (0x00): No sender authentication
- `PSk` (0x01): Pre-shared key authentication
- `Auth` (0x02): Asymmetric key authentication
- `AuthPSk` (0x03): Both PSK and asymmetric authentication

#### KEM Algorithms

- `DHKEM_P256_HKDF_SHA256` (0x0010): NIST P-256 curve
- `DHKEM_X25519_HKDF_SHA256` (0x0020): Curve25519

#### AEAD Algorithms

- `AEAD_AES_128_GCM` (0x0001): AES-128 in GCM mode
- `AEAD_AES_256_GCM` (0x0002): AES-256 in GCM mode
- `AEAD_CHACHA_20_POLY_1305` (0x0003): ChaCha20-Poly1305
- `AEAD_EXPORT_ONLY` (0xFFFF): Key derivation only, no encryption

#### KDF Algorithms

- `KDF_HKDF_SHA256` (0x0001): HKDF with SHA-256
- `KDF_HKDF_SHA512` (0x0003): HKDF with SHA-512

### Creating a Scheme

```go
import (
    "github.com/bronlabs/bron-crypto/pkg/base/curves"
    "github.com/bronlabs/bron-crypto/pkg/encryption/hpke"
)

// Create cipher suite
cipherSuite, err := hpke.NewCipherSuite(
    hpke.DHKEM_X25519_HKDF_SHA256,
    hpke.KDF_HKDF_SHA256,
    hpke.AEAD_CHACHA_20_POLY_1305,
)

// Create scheme with curve
curve := curves.NewX25519()
scheme, err := hpke.NewScheme(curve, cipherSuite)
```

### Key Generation

```go
kg, err := scheme.Keygen()
sk, pk, err := kg.Generate(prng)
```

**Types:**
- `*PrivateKey[S]`: Scalar in the curve's scalar field
- `*PublicKey[P, B, S]`: Point on the elliptic curve

### Authenticated Mode

Auth mode proves sender identity:

```go
// Sender encrypts with authentication
enc, err := scheme.Encrypter(
    hpke.EncryptingWithAuthentication(senderSK),
)
ciphertext, capsule, err := enc.Encrypt(message, receiverPK, prng)

// Receiver decrypts and verifies sender
dec, err := scheme.Decrypter(
    receiverSK,
    hpke.DecryptingWithCapsule(capsule),
    hpke.DecryptingWithAuthentication(senderPK),
)
plaintext, err := dec.Decrypt(ciphertext)
```

### Pre-Shared Key Mode

PSK mode uses shared secrets:

```go
psk := []byte("shared-secret-key")
pskID := []byte("key-identifier")

// Encrypt with PSK
enc, err := scheme.Encrypter(
    hpke.EncryptingWithPreSharedKey(psk, pskID),
)
ciphertext, capsule, err := enc.Encrypt(message, receiverPK, prng)

// Decrypt with PSK
dec, err := scheme.Decrypter(
    receiverSK,
    hpke.DecryptingWithCapsule(capsule),
    hpke.DecryptingWithPreSharedKey(psk, pskID),
)
plaintext, err := dec.Decrypt(ciphertext)
```

### Application Info Context

Bind encryption to application context:

```go
info := []byte("MyApp-v1.0-User-Session")

enc, err := scheme.Encrypter(
    hpke.EncryptingWithApplicationInfo(info),
)

dec, err := scheme.Decrypter(
    receiverSK,
    hpke.DecryptingWithCapsule(capsule),
    hpke.DecryptingWithApplicationInfo(info),
)
```

### Complete Example

```go
package main

import (
    "github.com/bronlabs/bron-crypto/pkg/base/curves"
    "github.com/bronlabs/bron-crypto/pkg/base/prng/pcg"
    "github.com/bronlabs/bron-crypto/pkg/encryption/hpke"
)

func main() {
    prng := pcg.NewRandomised()
    
    // Setup scheme
    cipherSuite, _ := hpke.NewCipherSuite(
        hpke.DHKEM_X25519_HKDF_SHA256,
        hpke.KDF_HKDF_SHA256,
        hpke.AEAD_CHACHA_20_POLY_1305,
    )
    curve := curves.NewX25519()
    scheme, _ := hpke.NewScheme(curve, cipherSuite)
    
    // Generate keys
    kg, _ := scheme.Keygen()
    receiverSK, receiverPK, _ := kg.Generate(prng)
    senderSK, senderPK, _ := kg.Generate(prng)
    
    // Encrypt with authentication
    message := []byte("Secret message")
    enc, _ := scheme.Encrypter(
        hpke.EncryptingWithAuthentication(senderSK),
    )
    ciphertext, capsule, _ := enc.Encrypt(message, receiverPK, prng)
    
    // Decrypt and verify
    dec, _ := scheme.Decrypter(
        receiverSK,
        hpke.DecryptingWithCapsule(capsule),
        hpke.DecryptingWithAuthentication(senderPK),
    )
    plaintext, _ := dec.Decrypt(ciphertext)
    
    // plaintext == message
}
```

### KEM/DEM Direct Access

For advanced use cases, access KEM and DEM directly:

```go
// Key Encapsulation Mechanism
kem, err := scheme.KEM()
sharedSecret, capsule, err := kem.Encapsulate(receiverPK, prng)

// Data Encapsulation Mechanism
dem, err := scheme.DEM(receiverSK)
sharedSecret, err := dem.Decapsulate(capsule)

// Direct AEAD access
aead, err := scheme.AEAD(symmetricKey)
ciphertext := aead.Seal(nil, nonce, plaintext, additionalData)
```

## Performance Considerations

### Paillier

- Key generation: ~100ms for 2048-bit keys
- Encryption: ~10ms per operation
- Decryption: ~5ms with CRT optimization
- Self-encryption: 2x faster than regular encryption

### HPKE

- Key generation: less than 1ms
- Encryption: less than 1ms
- Decryption: less than 1ms
- X25519 is ~10x faster than P-256
